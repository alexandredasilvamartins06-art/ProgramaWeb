1. Hiperlinks

Analogia: um link é uma porta que leva a outro lugar. Pode ser uma porta para outro cômodo da sua casa (outra página do seu site) ou para a casa do vizinho (outro site).

O que é?

O link usa a tag <a> (de anchor, âncora). Ela precisa de um atributo: uma informação extra escrita dentro da tag de abertura. O atributo do link é o href, que diz para onde a porta leva.

Exemplos:

<!-- Link para outro site -->
<a href="https://www.senai.br">Site do SENAI</a>

<!-- Link para outra página do seu site -->
<a href="contato.html">Fale conosco</a>

<!-- Abrir em nova aba -->
<a href="https://www.google.com" target="_blank">Abrir o Google</a>

<!-- Link de e-mail -->
<a href="mailto:contato@email.com">Mande um e-mail</a>
  • Link externo: endereço completo, começando com https://.
  • Link interno: só o nome do arquivo, se estiver na mesma pasta.
  • target="_blank": abre o link em uma nova aba.

Micro-passos

  1. Crie o arquivo contato.html com um <h1>Contato</h1>.
  2. No index.html, crie um link para contato.html.
  3. No contato.html, crie um link de volta para index.html.
  4. Clique nos dois e passeie entre as páginas!

Pequena vitória

Seu site agora tem mais de uma página ligada entre si. Isso é navegação de verdade!

Errou? Faz parte!

  • Clicou e apareceu "Arquivo não encontrado"? Confira se o nome no href está exatamente igual ao do arquivo, com minúsculas e extensão .html.
  • O link externo não abriu? Faltou o https:// no começo.

Links para dentro da mesma página

Um link pode levar a uma parte da própria página, como um elevador que vai direto ao andar certo. Basta dar um id ao destino e usar # no href: 

<a href="#contato">Ir para o contato</a>

...

<section id="contato">
    ...
</section>

Exercícios

  1. Crie um pequeno menu com links para index.html, sobre.html e contato.html.
  2. Coloque um link para um site externo que abra em nova aba.
  3. No fim de uma página longa, crie um link "Voltar ao topo" usando #.
